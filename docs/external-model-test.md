# 外部数据模型测试 / External-data model test

更新：2026-11-26。适用应用 `6.2.0` / 分析 `2.2.0`。本文件记录用两份外部数据检验 6.1.0 引入的预测带与模型选择行为；它不改变契约，也不把结果升级为独立生物学验证。分析 `2.2.0` 只改动研究工作的轮廓端点与相关残差敏感性，本测试不经过这两条路径，因此下表数字与 `2.1.0` 时相同。6.2.0 重跑产物 SHA-256 为 `0d3aec13…`（只嵌入的应用版本变化，数值逐项不变）。

## 目的

6.1.0 新增了 80% 整轨迹预测带、有限样本分辨率拒绝和拟合状态报告。需要回答：

1. 换一个实验室的数据，流程是否仍能导入、拟合并如实报告状态？
2. 80% 带在真实留出曲线上的覆盖率是多少？是否与模拟研究的 73.1% 一致？
3. 模型是否真的比训练均值基线更好？

## 数据

**A. 独立实验室（技术重复）**
- El Karoui 实验室棋盘试验，`Positive control P` 的 5 个无药孔（E12、F12、G12、H11、H12）。
- DOI `10.5281/zenodo.15311905`，CC0 1.0；E. coli SJR206（K-12 MG1655 背景），M9 + 葡萄糖 + 氨基酸，37 °C，96 孔板，每 7 分钟读数，27.8 小时，226 个时间点。
- 源数据已由作者做空白校正；早期负值原样保留。**这是同一块板的 5 个孔，不是 5 个独立生物重复。**

**B. 同实验室、新培养基条件**
- Aida & Ying BW25113 扩展验证：12 个条件，每个 8 条训练 + 4 条留出，48 个共同时间点。
- DOI `10.6084/m9.figshare.28342064.v1`，CC BY 4.0；与内置数据共用同一平板读数流程，因此**不是独立实验室验证**。

## 方法

- 直接调用 `runGrowthModelComparison()`（`small` 预算、根种子 `3817`、整曲线留出），绕开研究工作流对内置数据集 ID 的硬约束，但使用同一套模型、CV、选模和预测带实现。
- A：5 折，每折留 1 个孔，4 条训练。
- B：12 个条件，各 8 条训练、4 条留出。
- 预测带覆盖率：对每条留出曲线，计算预测时间点上的最大绝对残差，`≤ radius` 记为覆盖。
- 报告写入 `data/derived/external-model-test.json`；连续两次运行字节一致（SHA-256 `63bb513a…`）。

## 结果

### A. 独立实验室（5 折）

| 指标 | 结果 |
| --- | --- |
| 选中模型 | 5/5 折均为 `training_mean` |
| 开发 macro RMSE | 0.00999 – 0.06629（均值 0.03900） |
| 模型 − 基线差值 | 5/5 折为 0 |
| 80% 预测带 | 5/5 折不可用（`insufficient_finite_sample_resolution`） |
| Logistic / Gompertz 收敛 | 全部未收敛 |

4 条训练曲线只产生 2 个校准单元，低于 80% 所需的 4 个；流程按要求拒绝给出半径，而不是输出一个看似可用的数字。

### B. 同实验室新条件（12 条件 × 4 条留出 = 48 条曲线）

| 指标 | 结果 |
| --- | --- |
| 选中模型 | 12/12 条件均为 `training_mean` |
| 开发 macro RMSE | 0.00365 – 0.03401（均值 0.01253） |
| 模型 − 基线差值 | 12/12 条件为 0 |
| 预测带半径 | 0.01025 – 0.12025（均值 0.04806） |
| 整轨迹覆盖 | **35/48 = 72.9%**（Wilson 95% CI 59.0–83.4%） |
| 逐条件覆盖 | 1/4 到 4/4 |

**与模拟研究的一致性**：参数化模拟在“校准组噪声尺度、4 个校准单元”下给出 73.08%；这里的真实留出曲线给出 72.92%。两条独立路径给出几乎相同的点估计，说明模拟器没有明显偏离实际数据生成过程。

**统计解读**：点估计低于名义 80%，但 48 条曲线给出的 95% 区间（59.0–83.4%）仍包含 80%。因此正确表述是“未证明达到 80%，点估计偏低且与模拟一致”，而不是“已证明低覆盖”。

### 对 6.1.0 声明的核对

| 声明 | 外部数据表现 | 判断 |
| --- | --- | --- |
| 校准单元不足时拒绝给出带 | 5/5 折返回 `insufficient_finite_sample_resolution` | 成立 |
| 80% 带只在校准单元 ≥4 时可用 | 8 条训练 → 4 校准，12/12 条件可用 | 成立 |
| 不把未收敛拟合显示为可用估计 | 17/17 次运行中参数模型均标未收敛，选中均值基线 | 成立 |
| 模型优于基线 | 17/17 次运行差值为 0 | 不成立，且流程未这样声明 |
| 带覆盖率达到名义 80% | 点估计 72.9%，CI 含 80% | 未证实 |

## 局限

- A 是同一块板的 5 个孔，只反映孔间技术变异；B 与内置数据同实验室、同读数流程。两者都不能替代独立生物批次或独立实验室验证。
- 使用 `small` 预算（DE 80 / NM 80），参数模型普遍未收敛；因此“模型不优于基线”只代表当前预算下的结果，不能断言充分优化后仍较差。
- 预测带覆盖率只评估了 `training_mean` 分支；参数模型分支未覆盖。
- 48 条曲线的覆盖率区间很宽，不能据此精确估计真实覆盖率。
- 外部数据为空白校正值，早期存在负 OD；流程按规则保留并给出 `NEGATIVE_OD_SOURCE_CONTEXT_REQUIRED`，未做裁剪。

## 复现

```bash
npm run benchmark:external
```

输出 `data/derived/external-model-test.json`。数据来源与提取说明见 `data/external/elkaroui-2024/SOURCE.md` 与 `docs/research/2026-11-26-bw25113-expanded-real-data-validation.md`。

## 结论

6.1.0 的新增行为在外部数据上按设计工作：校准单元不足时拒绝给出预测带，未收敛拟合不被当作可用估计，模型选择继续落在均值基线上。预测带的实际覆盖率点估计为 72.9%，与模拟研究的 73.1% 一致，但尚不能证明达到名义 80%。因此本版继续把预测带描述为“校准组条件下的探索性同时带”，不声明 90%/95%，也不声明模型优于基线。
