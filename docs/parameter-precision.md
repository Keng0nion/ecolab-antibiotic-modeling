# 参数精度诊断 / Parameter-precision diagnosis

更新：2026-11-26。适用应用 `6.1.0` / 分析 `2.1.0`。本文件回答两个问题：当前参数能不能更准；如果不能，具体卡在哪一步。所有数字可用 `npm run benchmark:precision` 复现。

## 结论

1. **当前“拟合未收敛 / 轮廓未评估”是预算问题，不是数据不可识别。** `small` 预设在 160 次评价时耗尽预算；同一份数据在 `standard` 预算（415 次评价；本探针关闭大部分辅助分析，约 1.5 秒）收敛，轮廓状态变为 `ASSESSED`。
2. **收敛后的 ±0.34% 也不能直接当作可信精度。** 训练残差的滞后 1 自相关为 0.918，设计效应 40.5，有效样本约 8.7 而不是 352。按此膨胀，`psiMax` 的诚实半宽约 ±2.2%，初始状态约 ±3.9%。
3. **有些参数无论怎么加预算都不可识别**：绝对 CFU 尺度、`K`、`scaleOd` 的绝对尺度，以及任何杀菌参数。这是结构或设计问题，不是优化问题。

## 预算实验

| 预设 | 评价次数 | 终止原因 | 拟合状态 | 轮廓状态 | psiMax 95% | 初始状态 95% |
| --- | --- | --- | --- | --- | --- | --- |
| `small` | 160 | `maximum_evaluations` | `FIT_NOT_CONVERGED` | `NOT_ASSESSED` | 无 | 无 |
| `standard` | 415 | `converged_simplex` | `FIT_COMPLETED` | `ASSESSED` | [0.42162, 0.42454]，±0.345% | [4.58562, 4.64182]，±0.608% |
| `large` | 5750 | `converged_simplex` | `FIT_COMPLETED` | `ASSESSED` | 同上，差 <1e-8 | 同上，差 <1e-8 |

`standard` 与 `large` 给出相同估计与区间，说明 415 次评价已到局部最优；继续加预算不会改变数字。因此“未收敛”只影响状态展示，不影响这组数据的最优解。

## 逐个参数说明

| 参数 | 能否估计 | 当前精度 | 主要限制 |
| --- | --- | --- | --- |
| `psiMaxLog10PerHour` | 能，局部可识别 | iid 轮廓 ±0.345%；诚实约 ±2.2% | 误差模型、模型误设、`K` 固定 |
| `initialStates.pooled.log10PopulationDensity` | 能，局部可识别 | iid 轮廓 ±0.608%；诚实约 ±3.9% | 无 t0、早期点接近基线、与 `psiMax` 相关 −0.994 |
| `carryingCapacityLog10CfuPerMl`（K） | **不能** | 固定 `10^9`，不由数据估计 | OD 只识别 `s/K` 的乘积；需 CFU 校准 |
| `baselineOd` / `scaleOd` | 剖面干扰参数 | 不报告为科学参数 | `scaleOd` 与 `K` 混淆；只在训练侧剖面 |
| `errorSigmaLog10`（OD 路径） | 解析剖面 | 不报告区间 | 同方差假设；实际残差异方差且自相关 |
| `psiMin` / `kappa` / `zMIC` | **完全不能** | 无估计 | 内置数据无药物暴露；不是精度问题，是设计上不可能 |

## 为什么精度上不去（详细原因）

**1. 误差模型与有效样本**
`OD = b + s(N/K)` 的最小二乘假设独立同方差高斯残差。实测训练残差滞后 1 自相关 **0.918**，曲线间 ICC **0.62**，设计效应 `1+(44−1)×0.918 = 40.5`，有效样本 **8.7**。352 个观测不是 352 份独立信息；按设计效应膨胀，轮廓半宽应乘以约 **6.4**。该 0.918 是在“每时刻训练均值”残差上估计的，包含曲线偏移与模型失拟，因此 6.4 倍是上界；真实膨胀介于 1 与 6.4 之间。

**2. 独立单元只有 8 条曲线**
曲线间 SD `0.00295` 与曲线内 SD `0.00230` 同量级，ICC 0.62。参数不确定性主要来自“曲线之间”，而不是“点之间”；增加同一条曲线的时间点几乎不降低这部分方差。

**3. 结构混淆**
`K` 固定为 `10^9`，观测层只出现 `s/K`，因此 `K` 与 `s` 的绝对尺度不可分。`psiMax` 与初始状态的相关为 **−0.9937**，归一化雅可比条件数 **18.87**：似然面是一条狭长山谷，两个边缘轮廓区间可以很窄，但联合方向仍然弱。

**4. 设计信息不足**
数据从 0.5 h 开始，没有 t0，也没有迟滞期模型；早期 OD 约 0.08，接近基线噪声（约 0.001–0.002）。初始状态主要由这些低信号点决定，`psiMax` 主要由指数期斜率决定，两者通过“起点—斜率”权衡耦合。

**5. 模型误设**
训练 CV 中均值基线优于 Logistic 与 Gompertz；潜在 Logistic 也可能没有捕捉真实曲线形状。局部曲率再小，也不能消除模型偏差；偏差不在任何区间内。

**6. 单板单条件**
所有曲线来自同一条件、同一读数流程。区间条件于这块板；批次或孔间系统差异会以偏差形式进入，而不是方差。

**7. 局部性**
轮廓是局部曲率诊断。`large` 的 3 次重启收敛到同一点，支持“局部唯一”，但仍不是全局最优或结构可识别性的证明。

## 提高精度的路径（按性价比）

| 措施 | 预期效果 | 代价 |
| --- | --- | --- |
| 研究运行默认改用 `standard` 预算 | 从 `NOT_ASSESSED` 变为可评估；1.5 秒 | 免费，改默认值或提示 |
| AR(1)/cluster-robust 或层次随机截距 | 区间变诚实（预计半宽扩大 2–6 倍） | 中；改变区间语义，需升分析版本 |
| 独立曲线 8 → 32 | 曲线间标准误约减半 | 需新实验 |
| CFU 校准（≥3 个密度）+ t0 | 识别 `K` 与绝对尺度，打破 `psiMax`–初始混淆 | 需新实验 |
| 设计：有意改变初始密度、增加指数期采样 | 直接削弱 `psiMax`–初始相关性 | 需新实验 |
| 层次模型借用曲线间信息 | 降低曲线级参数方差 | 中高；与误差模型一起做 |

## 目标与代价（粗略）

- 把诚实半宽从 ±2.2% 降到 ±1%：约需 5 倍独立曲线（约 40 条），或在 AR(1) 修正后再增加约 5 倍。
- 识别 `K`：至少 3 个已知密度的 CFU 校准点；仅靠 OD 无法做到。
- 识别杀菌参数：需要加药时间-杀菌数据（CFU 或存活分数），无药 OD 数据永远不行。

## 复现

```bash
npm run benchmark:precision
```

输出 `data/derived/parameter-precision.json`，含三种预算的状态、估计、条件数、相关、轮廓区间，以及残差自相关、ICC、设计效应与有效样本。

## 边界

本诊断不改变现有契约；它说明两件事：把预算调到 `standard` 可以立即消除“未收敛”的展示问题；但要把“±0.34%”当作可信精度，需要先修正误差模型并增加独立曲线。当前版本继续把区间描述为条件性、探索性结果。
