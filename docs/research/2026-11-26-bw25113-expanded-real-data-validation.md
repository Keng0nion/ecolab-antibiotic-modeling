# BW25113 实测 OD600 扩展拟合对照

**日期：** 2026-11-26  
**用途：** 用未处理的 *E. coli* BW25113 实测 OD600 曲线扩展 Ecolab 同域拟合、整条曲线留出预测和 R 语言独立复算。

## 数据来源与范围

数据来自 Aida 与 Ying 的公开数据集。论文报告 13,608 条 BW25113 生长曲线、1,029 种化学成分明确的培养基；Figshare 页面提供实验原始曲线、培养基组成和曲线质量信息，并标为 CC BY 4.0。[论文](https://doi.org/10.1038/s41597-025-05356-3) · [Figshare 数据集](https://doi.org/10.6084/m9.figshare.28342064.v1)

本次只用 Round01 工作簿中的 2,628 条曲线。它们与组成表、质量表按 Label 逐一连接，2,628 条均匹配，未发现 Assay ID 或 Condition ID 冲突。工作簿时间列有 97 个半小时点，覆盖 0.5–48.5 小时。来源质量标记中 2,425 条通过，203 条未通过。

筛选条件时只纳入来源质量标记 `K_info = 0` 且 `r_info = 0` 的曲线。排除先前已用于开发对照的 Cond00003 后，有 23 个条件各有 12 条合格曲线，并至少共享 48 个时间点。按 Condition ID 排序后等距抽取 12 个条件，每组 8 条训练、4 条开发留出，覆盖 0.5–24 小时的 48 个共同点。角色按固定种子 3817 在整条曲线上随机划分，避免按标签顺序把前后批次固定分到训练与留出。

另对 Cond00003 做大样本同条件检查：从排除旧开发曲线后的合格曲线按标签顺序等距抽取 60 条，再用种子 3817 分成 48 条训练和 12 条开发留出。所有曲线截取相同的 36 个点（0.5–18 小时）。这些开发曲线用于对照，不视为盲测证据。

这些都是直接 OD600 记录。计算没有把 OD 换算成 CFU，没有推断抗生素效果，也没有从原始曲线估算细胞数。论文说明其派生的 K/r 指标计算会扣除培养基背景；本次拟合使用数据工作簿中的曲线值，不额外重算 K/r。

## 方法与 R 复核

Ecolab 对每组训练曲线用整条曲线留一法（12 条条件组为 8 折；Cond00003 为 6 折、每折留 8 条），比较 `training_mean`、logistic、Gompertz 三个直接 OD 模型。按每条留出曲线 RMSE 的宏平均选择模型。随后仅用训练曲线拟合所选模型，并计算开发曲线宏 RMSE 和合并 RMSE。

R 4.6.2 使用 base R 的有界 L-BFGS-B、多起点重新拟合 logistic 和 Gompertz，并独立计算同一组整曲线折分。R 与 JS 的 39 个条件/模型 CV 分数最大绝对差为 **4.1 × 10⁻⁸ OD600**；13 组的模型排序和所选模型全部一致。训练均值分数由两边按相同时间点直接计算。

## Cond00003 大样本检查

48 条训练曲线的 6 折 CV 分数：均值模型 **0.009313074**、logistic **0.011877953**、Gompertz **0.013768362**。均值模型胜出。12 条留出曲线的宏 RMSE 为 **0.007237842**，合并 RMSE 为 **0.009801359**。

覆盖率样本只有 12 条开发曲线，且整个来源曾用于本项目的数据探索，所以它只用于暴露明显的区间问题，不能作为正式覆盖率保证。区间较宽；单点覆盖高也不能替代整条轨迹覆盖结论。

## 算法决定与复现

这轮没有发现需要改动生产模型的证据：在同域、相同时间网格上，简单的逐时间点训练均值比两种 sigmoid 模型在新增条件的整曲线 CV 中更低。保留当前模型和候选集，避免把更复杂的曲线形状模型误当成更准。较高误差的 Cond00090 与 Cond00092 以及开发集误差高于 CV 的现象，应作为后续检查实验批次差异、曲线异质性和跨时间预测的依据。

R 独立重拟合约需一分钟级运行时间。使用随机整曲线折分时，R/JS 两侧模型排序一致，CV 分数最大差仅 `4.1e-8`，对照没有显示异常拟合回归。当前 R 脚本以共享 CSV 的 SHA-256 固定数据指纹。

复跑命令（从仓库根目录）：

```sh
node scripts/benchmarks/validate-bw25113-expanded.js --output-dir data/derived/figshare-bw25113-expanded-validation
Rscript scripts/benchmarks/validate-bw25113-expanded.R data/derived/figshare-bw25113-expanded-validation
```

导出的逐曲线、逐时间点数据、各候选模型分数和逐条留出误差分别保存在 `observations.csv`、`model-scores.csv` 和 `heldout-trajectories.csv`。R 分数保存在 `r-model-scores.csv`，JS 汇总和来源校验指纹保存在 `ecolab-results.json`。
